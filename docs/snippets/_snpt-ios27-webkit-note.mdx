**iOS 27+ and macOS 27+ (Safari): impact on web integrations.** Starting with iOS 27 and macOS 27, WebKit blocks browser requests to `uidapi.com`. This affects all browsers on iOS 27+ (including Safari and Chrome) and Safari on macOS 27+.

On affected browsers, the following operations fail:
- Loading the UID2 SDK for JavaScript from the UID2 CDN
- Generating UID2 tokens from the browser
- Refreshing UID2 tokens from the browser
