These messages include HTTP status codes (for example, `HTTP response code 403`) or exception types (for example, `exception: IOException`). Retry, and if the error persists contact UID2 support.<br/>**Opt-out metadata errors**: Verify that the operator can reach the UID2 opt-out service endpoint over outbound HTTPS (port 443), and that the operator key is valid for the environment.<br/><br/>If this error occurs at startup, the operator exits.
